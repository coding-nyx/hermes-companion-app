# Vision board

Open [vision-board.html](vision-board.html) in a browser. That file is the board: thesis, tokens, type, eight north-star frames.

## Thesis

Void, signal, type. Black field. One living color (`#00E5C3`) for “Hermes is here.” Hairline geometry. Mono for machine state, sans for human words.

If a mock looks like a cyberpunk poster, it is wrong. If it looks like a calibrated instrument, it is right.

## Frames

1. Connect / pair
2. Threads
3. Live turn
4. Approval strip
5. Profile switcher
6. Gateway HUD
7. Device armed
8. Device live (filmstrip drawer)

Each frame also exists as empty / loading / error / offline in implementation. The board shows the live state.

## Not this

No neon city, rain, kanji watermarks, chrome bevels, glassmorphism, bounce spinners, or second accent green.
